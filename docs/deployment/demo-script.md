# Activityual Cloud Demo — 5 to 10 Minutes

## Suggested recording length: 8 minutes

| Time | Demonstration |
|---|---|
| 0:00–0:40 | Introduce Activityual and its microservice architecture |
| 0:40–2:40 | Open deployed frontend, register/login, show dashboard |
| 2:40–3:40 | Create a new activity and mark it completed or missed |
| 3:40–4:30 | Show Analytics and Recommendations pages; accept a recommendation |
| 4:30–5:20 | Show ECS cluster and six running services |
| 5:20–6:00 | Show ECR images, ALB listeners and healthy target groups |
| 6:00–6:50 | Show RDS and DynamoDB tables |
| 6:50–7:40 | Show EventBridge bus/rules, Lambda configuration and logs |
| 7:40–8:00 | Summarize architecture and deployment |

## Recording checklist

- Use the deployed application URL.
- Use a test account and non-sensitive sample data.
- Show a successful user journey rather than only slides.
- In AWS Console, show critical configuration screens for ECS, ECR, ALB, RDS, DynamoDB, EventBridge and Lambda.
- Show CloudWatch logs for event processing only if a real successful invocation has been verified.
- Do not show credentials, secrets, tokens or private user data.
- Keep the recording between 5 and 10 minutes.
